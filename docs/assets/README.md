# Visual asset inventory

The README's public visual surface is intentionally small and evidence-backed.

- `readme/repopact-hero.svg` is the current deterministic hero: it explains the
  fragmented-session to durable-repository transition without mutable release
  numbers, metrics, or generic AI imagery.
- `readme/repopact-hero-social.png` is the generated 1280×640 social-preview
  raster derived from that same hero.
- `readme/workbench-governance.jpg` is a real Windows Workbench capture of the
  validated development repository in the Work lifecycle view. It is labelled
  as current-development evidence in the README.
- `repopact-governance.svg` and `repopact-flow.svg` are legacy diagrams. They
  contain stale release/count language and are not linked from public launch
  copy. They remain in place as historical assets until a separately governed
  cleanup decision authorizes removal or archival.
