# RepoPact arXiv source package

This directory is a submission-ready preparation package for the RepoPact preprint. It is
frozen against the RepoPact 3.1.0 release-candidate implementation snapshot
`6d782116fc9762da00439cf079d0f50585fea52`.

The package separates stable 3.1.0 product surfaces from active WI063/WI065
implementation checkpoints and from research infrastructure. It preserves the
explicit status **ARXIV NOT SUBMITTED**; rebuilding this package is not an
arXiv publication action.

Contents:

- `main.tex` — LaTeX manuscript with title, author, affiliation, abstract, keywords,
  reproducibility statement, and reconciled implementation boundaries.
- `references.bib` — bibliography source.
- `figures/` — repository-relative copies of the two manuscript figures.
- `build/` — isolated compiler output and inspection renders; generated locally and not part
  of the source package.

This is preparation only. No arXiv account, license selection, endorsement, or submission
was performed. The manuscript does not claim comparative model results, protected-admission
closure, or macOS/iOS validation, and does not claim that mobile mutation/export acceptance
is complete.
